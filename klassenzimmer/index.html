    📘 Vorzeichenregeln

    Klammern auflösen (Plus und Minus)

    + (+a) = + aplus plus → plus
    + (−a) = − aplus minus → minus
    − (+a) = − aminus plus → minus
    − (−a) = + aminus minus → plus

    Multiplizieren und Dividieren

    (+) · (+) = +gleiche Vorzeichen → Ergebnis positiv
    (−) · (−) = +
    (+) · (−) = −verschiedene Vorzeichen → Ergebnis negativ
    (−) · (+) = −(gilt genauso für „:“)

    Addieren: gleiche Vorzeichen → Beträge addieren; verschiedene Vorzeichen → Beträge subtrahieren, Vorzeichen der Zahl mit dem größeren Betrag.
